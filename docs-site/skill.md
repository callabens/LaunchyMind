# Skill

`skills/launchymind-preflight/SKILL.md` tells an agent when to run LaunchyMind and what it must not claim.

The agent does not decide ready, risky, or rejected. It quotes the rule id, the evidence, the source link, and the verified date. If a rule is unchecked, the agent says it could not be checked.

The agent does not write files unless you approve that exact fix, and it does not invent store-console answers.
